## Release delta classes

### A. Package / runtime semantic delta

Primary material delta:

- `src/rpos/routing.py` adds bounded Responsibility Routing classification;
- `src/rpos/__init__.py` exports the routing API;
- unresolved external-effect states can be classified as reconciliation hold rather than generic Human Return;
- repair and return-for-authorization remain distinct routes;
- route selection does not grant Authority.

### B. Tests / assurance delta

- `tests/test_responsibility_routing.py` checks Human Gate routing, reconciliation hold, repair vs resume authorization, and terminal-state behavior;
- existing formal-assurance ceilings remain applicable unless a new theorem is deliberately introduced for routing semantics;
- routing tests are runtime evidence, not legal/organizational Authority evidence.

### C. Public documentation / product-surface delta

Post-a2 `main` contains substantial documentation and B2B/public-surface refinement. These changes must be classified as current guidance versus historical/release-specific guidance before candidate freeze.

The current source routing notes explicitly preserve:

- `fail_closed != human_gate`;
- `evidence_transfer != authority_transfer`;
- `receiver_capability != receiver_eligibility`;
- `route_selection != authority_grant`;
- state recovery != approval/resume Authority recovery;
- Human Return is a bounded Responsibility Route, not a generic fallback.
