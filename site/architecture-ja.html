Verified architecture visuals

Responsibility Pathwayを、システム・ライフサイクル・証拠フローとして読む。

この3つのinteractive mapは、repository内のtyped JSONを正本とし、CIとPages deploy時に固定したArchify revisionでvalidate/renderされます。図はRPOSを説明しますが、runtime authority・operational evidence・sourceにないtopologyを生成しません。

3つの見方

問いが違えば、見るべき図も変わる。

Operational Architecture

proposal、Human Authority、RPOS Core、durable state、adapter boundary、external system、reconciliation、Observatory、Formal Assuranceを別々の責任として表示します。

Architecture mapを開く

Responsibility Lifecycle

実装されているRPOS state machineを、Human Gate、EFFECT_UNKNOWN、repair、Human Return、explicit resume、verified completionまで含めて表示します。

Lifecycle mapを開く

Formal Assurance Evidence Flow

exact source、Lean machine check、Python runtime test、source-bound assurance manifest、公開Viewerを、混同せず別のevidence layerとして表示します。

Evidence-flow mapを開く

Reproducibility

図にも公開sourceと固定rendererを持たせる。

正本となるdiagram inputは visuals/archify/ に保存します。CIはfork済みArchifyの 0853a805003514776bef3593ecca091409828902 を固定してrenderします。RPOS側diagram sourceまたはrenderer routeを変更した場合は、再度validationが必要です。

Visualization boundary

  • 図はoperationをauthorizeしない
  • 図はexternal effectを証明しない
  • 図はLean/Python evidenceを代替しない
  • sourceで確認した関係だけを表示する
